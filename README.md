# Projet Dérive Gaspésie

Des bouteilles lestées et scellées sont larguées dans le golfe du Saint-Laurent
pour mesurer les courants de surface. Chaque bouteille porte l'adresse
`derivegaspe.ca/N`. La personne qui la trouve signale sa position, puis la remet
à l'eau pour que la dérive continue.

Site : https://derivegaspe.ca
